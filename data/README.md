# Data notes

The workshop uses IBM's fictional **Telco Customer Churn** CSV (7,043 customers).

- Source: [IBM/telco-customer-churn-on-icp4d](https://github.com/IBM/telco-customer-churn-on-icp4d/blob/master/data/Telco-Customer-Churn.csv)
- Official sample description: [Telco customer churn (11.1.3+)](https://community.ibm.com/community/user/blogs/steven-macko/2019/07/11/telco-customer-churn-1113)
- This is **sample / fictional** customer data, not production PII.

If `data/raw/Telco-Customer-Churn.csv` is missing, download it:

```bash
python scripts/download_data.py
```
